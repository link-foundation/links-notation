experiments. They were included in addition to active packages. The issue's
initial detector missed the Gitpod Dockerfiles, nested Actions manifests and
some existing lockfiles; the repository inventory supplies those omissions.

## Existing components and deleted duplication

Prefer native package managers and their security databases over maintaining a
new resolver. `uv` provides both reproducible project locking and hashed pip
exports; Spotless provisions its supported formatter; glob/glob-parent replace
private minimatch internals. ESLint 10.15 supplies the fixed minimatch dependency
itself. Those upstream features remove custom classpath code and obsolete
override logic. Renovate, Dependabot, OSV, RustSec, Packagist advisories and
NuGet auditing cover complementary update/audit needs; switching bots is not
required to correct this repository's manifest coverage.

## Release audit failure

The initial branch CI run `43509344617` matched the initial SHA and completed
before diagnosis. Its saved release-audit step reports the C# registry fetch
failure on line 14 and exit 1 on line 23; nine other exact 0.31.3 deliveries
were verified. That log does not expose a transport error code, so it does not
prove a particular socket failure. The regression reproduces known transient
transport failures, retries them at most three times, and keeps HTTP errors,
invalid metadata and exhausted retries failing visibly. Credentials are never
printed. New version 0.31.4 prepares the normal release trigger; no successful
but skipped publish job is reported as delivery of 0.31.4.

See [validation.md](validation.md) for exact local coverage, archive limitations
and the latest CI state. The PR remains unmerged.

## Evidence formatting

Downloaded text is stored as UTF-8 without a BOM, with normalized trailing
whitespace. Original patch context spaces are preserved in the compressed
Dependabot `.diff.gz` snapshots. These formatting changes preserve their content
and satisfy the repository text policy.

Downloaded upstream Markdown release notes and changelogs are preserved as
`.md.gz` snapshots. Their 1,288 distinct absolute URLs included 1,189 GitHub HTML
URLs, adding over nineteen minutes at the existing one-request-per-second host
policy. Scanning these third-party documents exhausted the ten-minute link job
before it could report. Compression preserves the researched sources without
treating upstream relative links and historical changelogs as maintained project
documentation. Authored analysis, tables and primary-source links remain checked;
no link-check exclusions or timeout increases were added.
