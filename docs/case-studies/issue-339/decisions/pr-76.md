Closing this conflicting JS-only ordering draft; issue 63 remains open. Evidence
and the decision are recorded in PR 341:
<https://github.com/link-foundation/links-notation/pull/341>.

Issue 63 describes reversed order `(2 1)`, while this draft's arrow tests retain
the ordinary `(1 2)` order. It competes with PR 80 and provides no coordinated
seven-language contract. The maintainer also deprioritized the parser feature
and suggested an interpreter layer:
<https://github.com/link-foundation/links-notation/issues/63#issuecomment-3393009289>.

A future change needs to resolve the ordering contract first, then supply JS
tests and shared fixtures for the bindings it supports. The branch and issue
remain available; source, comments/reviews, run inventory, and linked traces are
archived. This closure removes no feature from current main.
