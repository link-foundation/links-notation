Closing this conflicting draft while preserving issue 184 for a coordinated
multi-reference design. Review and evidence are in PR 341:
<https://github.com/link-foundation/links-notation/pull/341>.

The final draft does add collection-based identifier APIs in Java and Go, along
with JS/Rust/Python/C#. Those changes replace scalar identifier access and can
throw or return errors for existing callers. PHP is absent, and the draft's old
Rust layout and identifier representation predate the current binary, Unicode,
streaming, and shared text contracts. Its own tests distinguish multi-part IDs
from contextual grouping in values, so the complete issue needs an explicit
semantic contract rather than a mechanical rebase.

No multi-reference feature is removed from current main by this closure. A fresh
implementation should start with JS contract tests, define compatibility with
quoted identifiers and the binary protocol, and supply all seven bindings or
reviewed exceptions. The branch and design evidence remain preserved; issue 184
stays open. PR 341 archives the diff, all comments/reviews, 113 run records, and
linked investigation traces, with expired logs recorded honestly.
