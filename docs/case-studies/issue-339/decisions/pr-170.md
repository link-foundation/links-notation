Closing this conflicting partial draft; issue 148 remains open. The decision and
archived evidence are part of PR 341:
<https://github.com/link-foundation/links-notation/pull/341>.

The draft changes punctuation/math tokenization and formatting in only part of
the bindings. Splitting previously valid unquoted references changes their
identity, and its quote preprocessing does not establish compatibility with the
current multi-delimiter quoting, Unicode, streaming, and versioned literals.
Rebasing would not resolve the missing shared contract or the unported bindings.

A future JS-first implementation should define the default/optional tokenization
behavior and add shared parse/format fixtures before coordinated ports. This
closure preserves the branch, feature issue, source diff, all comment types, run
metadata, and linked traces; no current parser feature is removed.
