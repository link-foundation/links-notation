Closing this conflicting partial draft while keeping issue 143 open for a
compatible seven-language delimiter design. Evidence is preserved in PR 341:
<https://github.com/link-foundation/links-notation/pull/341>.

The draft's independent opening/closing bracket alternatives allow mismatched
delimiter pairs. Java, Go, and PHP are not ported. It also predates the current
`~1{...}` reference literals and does not prove compatibility with literal
braces, quoted references, binary interoperability, or streaming.

A fresh JS-first change should reject mismatched pairs and establish those
compatibility fixtures before porting the syntax. The branch, diff, comments,
run inventory, and linked traces remain preserved in the case study; no existing
main feature is removed by closing the draft.
