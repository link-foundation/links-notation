    public class ParseException : FormatException, ISerializable
    Remarks

    The position is the furthest one the parser reached, which is the character the document stops making sense at rather than the point the last alternative gave up on. It derives from FormatException, the exception the generated parser raised on its own, so code that catches that keeps working.
