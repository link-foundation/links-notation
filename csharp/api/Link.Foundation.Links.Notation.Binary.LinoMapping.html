    Remarks
    • () is the null link 0.
    • A numeric reference n is (Number unary(n)), or an external reference when enabled.
    • Any other reference is (String code points…); code points are unary numbers or externals.
    • A link without an id and with exactly two values is a plain doublet.
    • A link without an id and any other number of values is a list.
    • A link with an id is (Identified id values…).
    • The document is a list of its top-level links, stored last (the root).

    A list or typed value with any number of values other than two is a single link of that many references when Arity allows it ([marker, elements…] for typed values, the bare elements for lists), and otherwise the doublet (marker chain), where chain is the nil-terminated cons list (e1 (e2 (… (en 0)))). Identical sub-links are emitted once and shared. Links are numbered so that every link only refers to earlier ones: doublets of plain doublets first, then the rest in creation order.
