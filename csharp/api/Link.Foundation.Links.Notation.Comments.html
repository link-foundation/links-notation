    Remarks

    # starts a comment when it opens a token: at the start of the document or after a space, a tab or a line break. A # written inside a token (issue#1047) or inside a delimited reference ("# not a comment") is an ordinary character.

    Remarks

    Every character of a comment is replaced rather than removed, so every later character keeps the position it had in the document the caller wrote, and anything the parser reports about a position still points at what the reader can see.
