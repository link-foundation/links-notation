    One node or token of the concrete syntax tree of a Links Notation document.

    Remarks

    Every character of a document belongs to exactly one token, so the text of the tree is the document itself, comments, blank lines, indentation, quotes and line endings included. A Document holds Line nodes; a line holds the tokens up to and including its line ending, and a parenthesized Group holds its own parentheses and the lines written between them. A group is part of the line it opens on, however many lines it spans. Read a tree with ParseCst(string).

    ToSExpression()

    The tree as an S-expression: (kind child ...) for a node and kind:"text" for a token, the text with </code>, ", line feeds, carriage returns and tabs escaped. Every Links Notation implementation writes the same S-expression for the same document, and two trees are the same exactly when their S-expressions are.
