### Fixed

- Read comments and delimited references token by token, as the grammar does,
  in all ten bindings. A `#` inside a reference that directly follows a group,
  another reference or a literal (`(a)" #b"`) is no longer blanked as a
  comment, and blanking a comment no longer turns an empty `""` into a
  reference holding the blanked text. The Swift and Kotlin differential tests
  against JavaScript failed on `main` because of this (fuzz-7412, fuzz-2359).
- A `StreamParser` waits for the line that closes an even run of quotes, so a
  stream reads `a "" b` followed by `"" c` as the whole document does.
- CI on `main`:
  - The release audit names the failed stage when the release job never ran,
    instead of blaming every registry's credentials.
  - Jobs that no hosted runner picked up (`kotlin / ios` on `macos-26`) are
    re-run.
  - A merge of a Dependabot pull request with `GITHUB_TOKEN` dispatches the
    push workflows it would otherwise never start.
  - The Maven floor is written as the range `[3.6.3,)`, which a Dependabot
    bump of `maven-enforcer-plugin` cannot rewrite, and the `maven-floor` job
    checks that it matches the Maven version it tests.
  - `check-dependencies.py --update` fails an update that changes nothing, and
    the declared floors the freshness check reported are raised.
  - The stale generated-parser gate names the peggy version and the command to
    run.
  - npm audit fails at `moderate`; minimatch is overridden to 11.0.4 under
    eslint; the Kotlin/JS `yarn.lock`, which neither npm audit nor Dependabot
    can read, is audited, and diff, glob and minimatch are raised past their
    advisories there.
  - The C# release can use NuGet.org trusted publishing (`NUGET_USER`), and
    an expired or rejected NuGet API key fails with the steps to renew it.
