### Fixed

- An even run of quotes followed by whitespace no longer reaches past its line
  (#443). `a ""\nb ""` reads as the two links `(a "")` and `(b "")` instead of
  `a` holding the text `\nb `; `""""` and `""""""` are empty the same way. A
  reference that spans lines still opens with a run followed by its first
  character (`""x\ny""`).
- A `#` that starts a value later on a line is the value, not a comment
  (#444): `tag #release` is the link of `tag` and `#release`. A `#` still opens
  a comment at the start of a line, and later on a line when whitespace, a
  parenthesis, a colon or the end of the document follows it, so
  `a: b # why` is unchanged.

### Changed

- Colons between two characters of an unquoted reference belong to it (#444):
  `12:30`, `std::string`, `https://example.com/a` and `a:b` are single
  references. This changes how such documents read: `a:b` and `12:30` used to be
  the links `(a: b)` and `(12: 30)`, and are now one reference each. A colon followed by
  whitespace, a parenthesis, a quote, the end of the document or a reference
  literal (`~1{62}`) still names a link, so `a: b`, `a:(b c)`, `a:"b"` and
  `a:~1{62}` read as before, and `a:b: c` is the link of `a:b` to `c`.

### Added

- `quoteReference` and `needsQuoting` in all ten bindings (named in each
  language's style) (#444). `quoteReference` is the existing reference escaping
  function under a shared name, and `needsQuoting` tells whether it would
  change a reference. Both stay conservative, so a quoted reference reads back
  as itself in any position.
