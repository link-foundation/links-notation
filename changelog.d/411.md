### Added

- Python: ship the PEP 561 `py.typed` marker in the wheel and sdist, so mypy
  and other type checkers use the package's annotations instead of reporting
  `import-untyped`, and add the `Typing :: Typed` classifier. The public API is
  fully annotated. CI type-checks the package with mypy and runs
  `mypy --strict` on a consumer of the built wheel installed in its own virtual
  environment. Prepare 0.31.6.
