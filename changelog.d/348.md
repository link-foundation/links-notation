### Added

- Pin Maven 3.10.0 for `java/` with the Maven Wrapper (`./mvnw`, checked by
  SHA-256) and enforce the 3.6.3 floor the build plugins need with
  `maven-enforcer-plugin`. CI also builds on Maven 3.6.3 and CMake 3.16.9, the
  declared floors, and on JDK 27 and Go 1.27.
- Check in CI that `.github/dependabot.yml` covers every committed manifest, and
  extend the dependency freshness gate to pre-commit `additional_dependencies`,
  the GoogleTest archive in `cpp/CMakeLists.txt` and the Maven Wrapper.

### Changed

- Require Python 3.11 or newer (`requires-python >=3.11`). Python 3.9 and 3.10
  are end of life and were never tested. CI now tests 3.11 and 3.15.
- Require Go 1.26 (`go` directive), since 1.24 and 1.25 are no longer
  supported. Apply the `go fix` modernizers.
- Move every Rust crate to edition 2024 and resolver 3. The minimum supported
  Rust version stays 1.87.
- Update every dependency in every language, including development tools,
  lockfile entries, GitHub Actions, runner images (`ubuntu-26.04`, `macos-26`)
  and the .NET SDK (10.0.402, read from `csharp/global.json`). Remaining
  transitive lag and the upstream reports are listed in
  `dev/log/issues/348/pulls/349`.
- Prepare version 0.27.0 across all eight bindings.

### Fixed

- Configure the C++ tests on CMake 3.16, the documented minimum: the build used
  a `FetchContent` keyword that needs CMake 3.24.
- Pin the pre-commit `eslint` hook to the project's ESLint and run it only on
  projects with an ESLint config; it failed on every run.
- Install the SDK `csharp/global.json` pins in the Gitpod workspace, whose
  image shipped .NET SDK 8.0.100 and could not build `csharp/`.
