### Added

- Add a C++17 binding in `cpp/` with every shared feature: the text parser and
  formatter, streaming parser, binary Links Notation codec, nesting limits,
  indented-document API, `Link` object model, `FormatConfig` and `LinksGroup`.
  It builds with CMake 3.16+, installs a `links_notation::links_notation`
  package for `find_package`, and is released as a source archive on the
  `cpp_VERSION` GitHub release for `FetchContent`.

### Changed

- Add C++ to the JavaScript-gated CI, the parity manifest and gate, the shared
  text fixtures, the cross-language binary interoperability check and the test
  comparison. C++ tests run with GCC, Clang, Apple Clang, MSVC and sanitizers.
- Prepare version 0.26.0 across all eight bindings.
