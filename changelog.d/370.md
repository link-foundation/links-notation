### Added

- Add a Kotlin Multiplatform binding as the tenth binding,
  `io.github.link-foundation:links-notation-kotlin`
  (package `io.github.linkfoundation.linksnotation`), for JVM, Android,
  iosArm64, iosSimulatorArm64, iosX64, JavaScript and WebAssembly (`wasmJs`),
  with no runtime dependencies. It is a hand-written recursive-descent port of
  the grammar with the features of the other bindings: `Parser` with
  `ParserOptions(maxDepth, maxInputSize, syntax)` and the sealed
  `ParseException` (`Syntax`, `DepthExceeded`, `InputTooLarge`), `Link`
  helpers, `formatLinks`, `FormatOptions`/`FormatConfig`, `LinksGroup`,
  indented documents, syntax metadata (`rawId`, `quote`), the lossless
  concrete syntax tree (`parseCst`), `StreamParser` and the binary codec.
- Run the shared text, syntax, binary and reference-literal fixtures on every
  Kotlin target (the `generateParityCases` Gradle task), add the binding to
  `parity/language-features.json`, CI (ktlint, JVM, JS, Wasm, Android, iOS,
  and a differential test against the JavaScript parser) and the binary
  interoperability check, and publish it to Maven Central from
  the coordinated release.
