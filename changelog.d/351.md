### Fixed

- Bundle the JavaScript package for browsers without a polyfill. `StreamParser`
  extended `EventEmitter` from Node's built-in `events` module, so bundlers that
  target browsers, such as `esbuild --platform=browser`, failed with
  `Could not resolve "events"` even when only `Parser` was imported. It now
  uses a built-in emitter with the same listener methods (`on`, `once`, `off`,
  `removeListener`, `emit`, `listenerCount` and others) and the same unhandled
  `error` behavior. It is no longer an `instanceof EventEmitter`. The package
  imports no Node.js built-in modules, and a test bundles both `src/` and
  `dist/` for the browser to keep it that way.
