### Added

- Add the Swift implementation as the ninth binding. It is a Swift package
  (`LinksNotation`, Swift 5.9+, macOS 13+, iOS 16+ and Linux, no dependencies),
  installed with SwiftPM from the repository's root `Package.swift`. It has the
  same features as the other bindings: parsing and formatting with
  `ParserOptions` limits and located errors, syntax metadata and the concrete
  syntax tree, `FormatOptions`, `LinksGroup`, `StreamParser`, indented documents
  and the binary links notation. The Rust compile-time macro is the one
  documented exception, as in every binding other than Rust.
- Port every JavaScript test file to XCTest. The Swift suite also runs the
  shared text and syntax fixtures and a differential test against JavaScript on
  random documents, and the binary interoperability job compares Swift's
  encoding with the other bindings'. CI builds, tests and lints it with Swift
  5.9 and the current Swift on Linux, and on macOS.
- Publish Swift releases as the bare version tag (`0.29.0`) that SwiftPM
  resolves, verified by building a package that depends on that exact tag.
