### Fixed

- Formatting with less parentheses reads back as the same link, in all ten
  bindings. `format(true)` of `((b c))` wrote `(b c)`, and of `()` wrote
  nothing, so `parse(link.format(true))` gave a different link. An anonymous
  link now keeps its parentheses when it holds exactly one link with values or
  no values at all. `(a b)`, `(a (b c))` and `((b c) (d e))` still lose theirs.
  `max_line_length` measures the same text that is written.
- `parity/text-fixtures.json` has the exact less parentheses text of every case,
  and every binding checks it and reads it back on each path it has.
