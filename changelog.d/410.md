### Fixed

- Stop posting `@dependabot rebase` from `AutoMerge.yml` with `GITHUB_TOKEN`.
  Dependabot accepts commands only from users with push access, so it rejected
  every one of them, and the sweep posted the comment again after each merge
  (five times on #396). Without a usable `DEPENDABOT_AUTO_MERGE_TOKEN`, behind
  pull requests are now named in a workflow warning that says how to update
  them. A `@dependabot rebase` or `recreate` request that Dependabot rejected,
  or that `github-actions[bot]` posted, no longer counts as pending, so a
  maintainer's request is still waited for but a rejected one is not.
- Close Dependabot pull requests that `main` has already superseded, with a
  comment naming the versions `main` has. A pull request is closed only when
  every line it adds outside its lockfiles is already on `main` in the same
  form with the same or a newer version (for example the GitHub Actions group
  #396 and the `csharp/global.json` SDK update #407 after #408). Anything that
  cannot be compared, and any pull request with commits by others, stays open.
